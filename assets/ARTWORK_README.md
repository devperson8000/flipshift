# FLIPSHIFT artwork pack

All runtime assets are WebP images loaded by `js/assets.js`. They were prepared from the generated FLIPSHIFT artwork and match the original manifest paths and game tile system.

- `player/player.webp`: robot player
- `tiles/tile_world1..4.webp`: world-specific tile textures
- `backgrounds/bg_world1..4.webp`: power plant, ice sector, foundry, core
- `collectibles/`: energy core, checkpoint states, exit gate
- `hazards/`: spike and drone
- `effects/`: optional dash and impact art

Only `js/assets.js` has been adapted for WebP paths. Gameplay physics, level layout, controls, and functionality are unchanged.
