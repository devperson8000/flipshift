# FLIPSHIFT
Static site, no build. Deploy: push to GitHub and import in Vercel (framework: Other), or run `vercel` here. Local: `npx serve` (ES modules need http, not file://).
js/game.js = physics+render, js/levels.js = the 4 worlds (edit the ops lists), js/main.js = menus/input/audio, js/save.js, js/assets.js.
